# 🚀 GS Dev Studio — Pacote de Skills para Codex

Este diretório contém a metodologia operacional e técnica completa desenvolvida para a **GS Dev Studio / GS Digital**, dividida em **3 Skills modulares prontas para uso no OpenAI Codex, Claude Code, Antigravity ou qualquer assistente de IA**.

---

## 📂 Estrutura das 3 Skills

### 1. `prospeccao-e-auditoria-leads`
- **O que faz:** Minera leads no Google Maps em bairros nobres, faz a triagem de nichos de alto ticket (clínicas, estética, advocacia, salões) e executa a **mini-auditoria técnica de 2 minutos** (verificação real de HTTPS, identificação de tag `noindex`, teste de botão de WhatsApp e pontuação de leads).
- **Arquivo:** [`prospeccao-e-auditoria-leads/SKILL.md`](./prospeccao-e-auditoria-leads/SKILL.md)

### 2. `vendas-mensagens-e-fechamento`
- **O que faz:** Contém a inteligência comercial e os scripts de primeiro contato no WhatsApp com ganchos técnicos reais, os **3 argumentos de ouro** (*Instagram ≠ Google*, *Credibilidade que Elimina a Pechincha* e *Investimento Único sem Queimar Caixa em Anúncio*), reunião consultiva de 20 min, superação de objeções e contratos de manutenção recorrente (R$ 189/mês).
- **Arquivo:** [`vendas-mensagens-e-fechamento/SKILL.md`](./vendas-mensagens-e-fechamento/SKILL.md)

### 3. `implantacao-seo-e-google-business`
- **O que faz:** Roteiro técnico completo de engenharia e publicação: arquitetura HTML/CSS/JS ultra-rápida, deploy automatizado no GitHub + Vercel com domínio próprio e SSL gratuito (com solução dos erros 404 e BOM), checklist de SEO técnico (Search Console, sitemap.xml, Schema.org LocalBusiness) e configuração blindada do Perfil da Empresa no Google (Google Meu Negócio) sem risco de suspensão.
- **Arquivo:** [`implantacao-seo-e-google-business/SKILL.md`](./implantacao-seo-e-google-business/SKILL.md)

---

## 🛠️ Como Usar no Codex

Cada pasta contém um arquivo `SKILL.md` no padrão universal de skills com frontmatter YAML (`name` e `description`).
Você pode:
1. Copiar as pastas diretamente para o diretório de skills do seu projeto ou ambiente Codex.
2. Referenciar o conteúdo de qualquer uma delas durante conversas para orientar a IA a prospectar, redigir mensagens ou configurar sites e SEO.
